
# Youth Red Cross (JCBUST)

## Health • Service • Friendship

<p>A responsive website developed for the Youth Red Cross Cell of J.C. Bose University of Science and Technology, YMCA, Faridabad, to showcase its activities, events, achievements, communities, and social welfare initiatives.</p>

## 📌 About the Project

<p>The Youth Red Cross website serves as a digital platform to represent the organization's mission and activities. It provides information about YRC, its coordinators, core team, events, communities, and various social service projects.</p>

<p>The website aims to spread awareness about humanitarian activities and encourage students to participate in community service.<p></p>

## ✨ Features
- Responsive and user-friendly interface.
- Home page introducing Youth Red Cross.
- About page featuring the organization's mission, achievements, coordinators, and core team.
- Events page showcasing activities and campaigns.
- Communities page highlighting different YRC communities and their responsibilities.
- Contact page for communication and queries.
- Social media integration.
- Modern design with interactive navigation.
